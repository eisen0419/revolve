    # Revolve

    > A self-reinforcing flywheel for AI research and evolution — packaged as a Claude Code plugin.

    ## What is Revolve?

    Revolve packages three battle-tested Claude Code skills into a single installable plugin:

    - **`/research-pipeline`** — Multi-source research: web + YouTube + NotebookLM → Obsidian notes
    - **`/evolve-claude-md`** — Analyze session learnings → append improvements to CLAUDE.md
    - **`/yt-search`** — YouTube search + transcript extraction
    - **`/revolve-setup`** — Interactive setup wizard for first-time configuration

    Together, they form a flywheel: research informs your AI's evolution, which makes future research better.

    ## Installation

    1. Install via Claude Code marketplace:
       ```
       /plugin install revolve
       ```

    2. Or clone and install manually:
       ```bash
       git clone https://github.com/your-username/revolve ~/.claude/plugins/revolve
       ```

    3. Run setup wizard:
       ```
       /revolve-setup
       ```

    ## Quick Start

    ```
    # Research a topic
    /research-pipeline "transformer attention mechanisms"

    # Deep research mode
    /research-pipeline --deep "RAG vs fine-tuning tradeoffs"

    # Search YouTube
    /yt-search "Andrej Karpathy neural networks lecture"

    # Evolve your CLAUDE.md after a productive session
    /evolve-claude-md
    ```

    ## Requirements

    - Claude Code 1.0+
    - Python 3.8+
    - `yt-dlp` (`brew install yt-dlp`)
    - `fswatch` (`brew install fswatch`) — for auto-sync
    - Obsidian (optional, but recommended)

    ## The Flywheel

    See [docs/flywheel.md](docs/flywheel.md) for the full architecture.

    ## Contributing

    See [CONTRIBUTING.md](CONTRIBUTING.md).

    # The Revolve Flywheel

    Revolve is built around a self-reinforcing loop: better research improves your AI's instructions,
    which makes future research more effective, which generates more learnings to feed back in.

    ## Architecture Diagram

    ```
    ┌─────────────────────────────────────────────────────────┐
    │                    THE REVOLVE FLYWHEEL                  │
    │                                                          │
    │   Research Topic                                         │
    │        │                                                 │
    │        ▼                                                 │
    │  ┌─────────────┐    web + YouTube    ┌───────────────┐  │
    │  │  /research  │ ──────────────────► │  NotebookLM   │  │
    │  │  -pipeline  │ ◄────────────────── │  Synthesis    │  │
    │  └─────────────┘    structured note  └───────────────┘  │
    │        │                                                 │
    │        │ Obsidian note                                   │
    │        ▼                                                 │
    │  ┌─────────────┐                                         │
    │  │  Knowledge  │                                         │
    │  │    Base     │                                         │
    │  └─────────────┘                                         │
    │        │                                                 │
    │        │ session learnings                               │
    │        ▼                                                 │
    │  ┌─────────────┐    improvements    ┌───────────────┐   │
    │  │  /evolve-   │ ──────────────────► │  CLAUDE.md    │   │
    │  │  claude-md  │                    │  (AI memory)  │   │
    │  └─────────────┘                    └───────────────┘   │
    │                                            │             │
    │                                            │ better AI   │
    │                                            ▼             │
    │                                    Next session is       │
    │                                    more effective ──┐    │
    │                                                     │    │
    │    ◄────────────────────────────────────────────────┘    │
    └─────────────────────────────────────────────────────────┘
    ```

    ## The Loop Explained

    ### 1. Research Input
    You start with a research question. `/research-pipeline` searches the web, extracts YouTube
    transcripts, and synthesizes findings via NotebookLM.

    ### 2. Knowledge Accumulation
    Research notes land in your Obsidian vault — searchable, linkable, persistent.

    ### 3. Learning Extraction
    After productive sessions, `/evolve-claude-md` analyzes what worked, what didn't,
    and proposes targeted improvements to your CLAUDE.md.

    ### 4. AI Evolution
    CLAUDE.md improvements make your AI collaborator smarter for future sessions —
    it learns your preferences, domain vocabulary, and effective patterns.

    ### 5. Compounding Returns
    Each research session both produces knowledge AND improves the tool doing the research.
    The flywheel accelerates over time.

    ## Components

    | Component | Role in Flywheel |
    |-----------|-----------------|
    | `/research-pipeline` | Knowledge acquisition |
    | `/yt-search` | Video knowledge source |
    | `/evolve-claude-md` | AI evolution mechanism |
    | `sync_conversations.py` | Conversation knowledge capture |
    | Obsidian templates | Knowledge organization |
    | `config.md` | Personalization layer |

    # Contributing to Revolve

    Thank you for your interest in contributing!

    ## Development Setup

    1. Clone the repository:
       ```bash
       git clone https://github.com/your-username/revolve
       cd revolve
       ```

    2. Run setup wizard to configure your local environment:
       ```
       /revolve-setup
       ```

    3. Install Python dev dependencies:
       ```bash
       pip install pytest
       ```

    ## Project Structure

    ```
    revolve/
    ├── .claude-plugin/       # Plugin manifest
    ├── skills/               # Claude Code skills
    │   ├── revolve-setup/
    │   ├── research-pipeline/
    │   ├── evolve-claude-md/
    │   └── yt-search/
    ├── scripts/              # Python sync scripts
    ├── templates/            # Obsidian templates
    ├── docs/                 # Documentation
    └── config.md.example     # Config template
    ```

    ## Contribution Guidelines

    ### Adding a New Skill

    1. Create `skills/<skill-name>/SKILL.md`
    2. Follow the existing SKILL.md format
    3. Add skill path to `.claude-plugin/plugin.json`
    4. Document in README.md and README_CN.md

    ### Modifying Existing Skills

    - Test changes with `/revolve-setup` fresh install
    - Ensure paths remain parameterized (no hardcoding)
    - Update CHANGELOG.md

    ### Pull Request Checklist

    - [ ] No hardcoded user-specific paths
    - [ ] config.md.example updated if new config fields added
    - [ ] docs/config-contract.md updated if config schema changed
    - [ ] CHANGELOG.md entry added
    - [ ] README.md and README_CN.md updated if user-facing changes
    - [ ] Python scripts pass `python3 -m py_compile`

    ## Commit Message Format

    ```
    <type>(scope): <summary>
    ```

    Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`

    ## License

    By contributing, you agree your contributions will be licensed under MIT.
