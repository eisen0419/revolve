    # /evolve-claude-md

    Analyze current session learnings and propose append-only improvements to CLAUDE.md.

    ## Trigger

    User runs `/evolve-claude-md` or asks to evolve / update / improve CLAUDE.md.

    ## Safety Constraints

    **APPEND-ONLY**: This skill ONLY appends new content to CLAUDE.md.
    It NEVER modifies, deletes, or rewrites existing content.
    Violation of this constraint is a critical error.

    ## Instructions

    ### Step 1: Locate CLAUDE.md

    1. Check `config.md` for a `claude_md_path` field (optional override)
    2. Default: look for CLAUDE.md in current project root, then `~/.claude/CLAUDE.md`
    3. If not found: ask user "Where is your CLAUDE.md?"

    ### Step 2: Analyze Session Learnings

    Review the current conversation for:
    - Patterns the user corrected (errors made and fixed)
    - New conventions established in this session
    - Recurring preferences the user expressed
    - Effective workflows discovered
    - Problems encountered and solutions found

    ### Step 3: Generate Improvement Proposals

    For each identified learning, draft a concise addition to CLAUDE.md:
    - Format: bullet point or short section header + bullets
    - Tone: prescriptive ("Always X", "Prefer Y over Z", "When X, do Y")
    - Scope: specific enough to be actionable, general enough to be reusable

    ### Step 4: Idempotency Check

    For each proposed addition:
    1. Search existing CLAUDE.md for similar content (keyword match)
    2. If similar content found: skip this proposal, note "already covered"
    3. Only present proposals that are genuinely new

    ### Step 5: User Confirmation

    Present proposed additions to user:
    ```
    Proposed additions to CLAUDE.md:

    1. [Section: Preferences]
       - Always use X when Y

    2. [Section: Patterns]
       - When debugging Z, start with W

    Approve all? (y) | Approve individually? (i) | Cancel? (n)
    ```

    Wait for user confirmation. Individual approval mode: present each proposal separately.

    ### Step 6: Append to CLAUDE.md

    For approved proposals:
    1. Read current CLAUDE.md end
    2. Append a `## Session Learnings — <date>` section if not already present today
    3. Append approved items under that section
    4. Confirm: "Added N items to CLAUDE.md"

    NEVER modify any existing content above the appended section.
