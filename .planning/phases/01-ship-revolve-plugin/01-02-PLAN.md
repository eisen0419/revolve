<context>
Origin: docs/plans/2026-04-02-001-feat-revolve-open-source-plugin-plan.md
Unit: 2 — Config System

config.md 是用户本地配置文件（不提交到 git），config.md.example 是模板。
所有 skill 通过读取 config.md 获取 vault_path、output_dir、screenshots_dir、sync_providers 等参数，
避免 hardcoded 路径。

Patterns to follow:
- config.md 使用 Markdown 格式，便于 Claude Code skill 直接解析
- 每个配置项附注释说明用途
- config-contract.md 作为规范文档，供 skill 开发者参考
</context>

    # Copy this file to config.md and fill in your values.

    ## Paths

    <!-- Path to your Obsidian vault root -->
    vault_path: ~/Knowledge Base

    <!-- Directory for research output notes (relative to vault_path or absolute) -->

    <!-- Directory for screenshots captured during research -->

    ## Sync Providers

    <!-- Comma-separated list of AI providers to sync conversations from -->

    ## Optional

  <name>Task 2: 创建 docs/config-contract.md</name>
  <files>docs/config-contract.md</files>
  <action>
    创建 docs/ 目录，写入配置契约文档：

    # Config Contract

    ## Overview

    All Revolve skills read configuration from `config.md` in the plugin root directory.
    This file is gitignored. Users copy `config.md.example` to `config.md` and fill in their values.

    ## Required Fields

    | Field | Type | Description |
    |-------|------|-------------|
    | `vault_path` | path | Absolute or `~`-prefixed path to Obsidian vault root |
    | `output_dir` | path | Directory where research notes are written |
    | `screenshots_dir` | path | Directory for captured screenshots |
    | `sync_providers` | list | Comma-separated AI providers: `claude`, `gemini`, `chatgpt`, `codex` |

    ## Optional Fields

    | Field | Type | Default | Description |
    |-------|------|---------|-------------|
    | `default_language` | string | `en` | Output language: `en` or `cn` |
    | `notebooklm_enabled` | bool | `true` | Enable NotebookLM auto-import |

    ## Parsing Convention

    Skills parse config.md line by line, matching `key: value` pattern.
    Leading/trailing whitespace is trimmed. Comment lines (starting with `<!--`) are ignored.

    ## Skill Responsibilities

    - Every skill MUST check for config.md existence at startup
    - If config.md is missing, skills MUST prompt user to run `/revolve-setup`
    - Skills MUST NOT hardcode any user-specific paths
  </action>
  <verify>cat docs/config-contract.md | grep vault_path</verify>
  <done>docs/config-contract.md 存在，包含字段契约表</done>
