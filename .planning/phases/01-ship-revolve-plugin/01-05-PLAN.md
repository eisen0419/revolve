    # /research-pipeline

    Multi-source research pipeline: web + YouTube + NotebookLM → structured Obsidian notes.

    ## Trigger

    User runs `/research-pipeline <topic>` or `/research-pipeline --deep <topic>`.

    ## Parameters

    - `<topic>`: Research topic or question (required)
    - `--deep`: Enable deep research mode with extended NotebookLM queries and cross-source validation

    ## Instructions

    ### Step 0: Config & Dependency Check

    Read `config.md`:
    - `vault_path`, `output_dir`, `screenshots_dir` — required
    - `notebooklm_enabled` — optional, default true
    - If config.md missing: "Run /revolve-setup first."

    Check dependencies:
    - yt-dlp: for YouTube transcript extraction
    - NotebookLM MCP: for deep research queries (if notebooklm_enabled)

    ### Step 1: Web Research

    Search for the topic using available web search tools.
    Collect 3-5 authoritative sources. For each source:
    - Extract key claims, data points, quotes
    - Note source URL and access date

    On error: log "Web research failed: <reason>", continue to next step.

    ### Step 2: YouTube Research

    Use yt-search logic to find 1-2 relevant YouTube videos.
    Extract transcripts and identify key insights.

    On error: log "YouTube research skipped: <reason>", continue.

    ### Step 3: NotebookLM Integration (if notebooklm_enabled)

    Import collected sources into NotebookLM notebook.
    Query: "Summarize key findings about <topic>"

    If --deep flag:
    - Additional query: "What are the contradictions or open questions?"
    - Additional query: "What are practical applications?"
    - Cross-validate findings across sources

    On error: log "NotebookLM step skipped: <reason>", continue.

    ### Step 4: Synthesize Research Note

    Compile all gathered information into a structured research note using the template at
    `templates/research-note.md`.

    Fill in:
    - frontmatter: topic, date, sources list
    - ## Summary: 3-5 sentence overview
    - ## Key Findings: bullet points with citations
    - ## Open Questions: unresolved issues
    - ## Sources: full URL list

    ### Step 5: Save to Obsidian

    Write the research note to:
    `<output_dir>/<YYYY-MM-DD>-<slugified-topic>.md`

    Report saved file path. If screenshots were captured, move to `screenshots_dir`.

    # NotebookLM Tools Reference

    ## Available MCP Tools

    | Tool | Description |
    |------|-------------|
    | `notebook_create` | Create a new notebook |
    | `source_add` | Add source (url/text/file/drive) |
    | `notebook_query` | Query notebook with a question |
    | `notebook_describe` | Get notebook summary |
    | `research_start` | Start guided research session |
    | `research_status` | Check research session status |

    ## Common Query Patterns

    ### Summarize Sources
    ```
    notebook_query(notebook_id, "Summarize the key findings across all sources")
    ```

    ### Extract Contradictions
    ```
    notebook_query(notebook_id, "What are the main contradictions or disagreements between sources?")
    ```

    ### Practical Applications
    ```
    notebook_query(notebook_id, "What are the practical applications of these findings?")
    ```

    ## Known Limitations

    - Max sources per notebook: 50
    - Max source size: ~500KB text
    - Audio overview generation: async, poll studio_status
    - Rate limits apply to frequent queries
