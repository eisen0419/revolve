    # /yt-search

    Search YouTube videos and extract transcripts for research purposes.

    ## Trigger

    User runs `/yt-search <query>` or asks to search YouTube / find video transcripts.

    ## Instructions

    ### Step 0: Dependency Check

    Verify yt-dlp is available: run `which yt-dlp`
    - If missing: "yt-dlp is required. Install via `pip install yt-dlp` or `brew install yt-dlp`"
    - Abort if dependency is missing.

    ### Step 1: Read Config

    Read `config.md` in the plugin root to get `output_dir`.
    - If config.md is missing: "Run /revolve-setup first to configure Revolve."
    - Default output_dir fallback: ~/Downloads/revolve-research

    ### Step 2: Search YouTube

    Use yt-dlp to search YouTube for the query:
    ```
    yt-dlp "ytsearch5:<query>" --get-id --get-title --get-description --no-download
    ```

    Present results as a numbered list with title and channel.

    ### Step 3: Select Video

    Ask user to select a video number, or enter a YouTube URL directly.

    ### Step 4: Extract Transcript

    Extract transcript/subtitles using yt-dlp:
    ```
    yt-dlp --write-auto-sub --sub-lang en --skip-download --output "<output_dir>/%(title)s.%(ext)s" <url>
    ```

    If no English subtitles available, try other available languages.

    ### Step 5: Format and Save

    Parse the subtitle file (vtt/srt) and format as clean text.
    Save to `<output_dir>/yt-<video-id>-transcript.md` with frontmatter:
    ```
    ---
    source: youtube
    url: <video_url>
    title: <video_title>
    date: <today>
    ---
    ```

    Report saved file path to user.
