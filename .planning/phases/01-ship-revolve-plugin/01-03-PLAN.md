    # /revolve-setup

    Interactive environment detection and configuration wizard for Revolve.

    ## Trigger

    User runs `/revolve-setup` or asks to set up / configure Revolve.

    ## Instructions

    ### Step 1: Welcome

    Greet the user and explain what this wizard does:
    - Detect environment (Obsidian vault, Python, system tools)
    - Collect required paths
    - Generate config.md

    ### Step 2: Dependency Check

    Check the following dependencies and report status:

    1. **Python 3.8+**: run `python3 --version`
       - If missing: "Install Python 3.8+ from https://python.org"
    2. **fswatch**: run `which fswatch`
       - If missing: "Install via `brew install fswatch`"
    3. **yt-dlp**: run `which yt-dlp`
       - If missing: "Install via `pip install yt-dlp` or `brew install yt-dlp`"

    Show a summary table. Non-fatal missing deps: warn but continue.

    ### Step 3: Detect Obsidian Vault

    Search common locations for Obsidian vault:
    - ~/Documents/
    - ~/Knowledge Base/
    - ~/Obsidian/
    - ~/Desktop/

    Look for directories containing `.obsidian/` folder.
    Present found vaults as numbered options. Allow manual path entry.

    ### Step 4: Collect Paths

    Ask the user for:
    1. `vault_path` — confirm detected vault or enter manually
    2. `output_dir` — default: `<vault_path>/Research`
    3. `screenshots_dir` — default: `<vault_path>/Research/screenshots`

    ### Step 5: Select Sync Providers

    Present checkboxes for supported providers:
    - [ ] claude
    - [ ] gemini
    - [ ] chatgpt
    - [ ] codex

    User selects which providers to sync conversations from.

    ### Step 6: Write config.md

    Check if `config.md` already exists in plugin root.
    - If exists: ask "config.md already exists. Overwrite? (y/n)"
    - If no or user declines: abort with message "Setup cancelled. Existing config preserved."

    Write config.md using the template from config.md.example with user-provided values.

    ### Step 7: Confirm & Next Steps

    Show summary of written config. Print next steps:
    ```
    Setup complete! Next steps:
    1. Run /research-pipeline to start a research session
    2. Run /evolve-claude-md to evolve your CLAUDE.md
    3. Run /yt-search to search YouTube videos
    ```
